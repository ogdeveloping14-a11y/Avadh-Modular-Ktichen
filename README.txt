PHONE / WHATSAPP NUMBER
-----------------------
The customer's actual number was not present in the supplied website files or readable from the supplied screenshots.

Add the real number only in:
  js/config.js

Example:
  PHONE_NUMBER: "9198XXXXXXXX"

Use the 91 country code, without +, spaces or dashes.

After adding the real number, every Call / WhatsApp button will use it automatically.
